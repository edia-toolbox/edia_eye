\doxysubsection{Detailed Description}
The {\ttfamily \doxylink{class_edia_1_1_eye_1_1_eye_data_handler}{Eye\+Data\+Handler}} class is responsible for receiving, managing, and distributing eye-\/tracking data to registered data clients. 


\begin{DoxyItemize}
\item Operates as a singleton, ensuring that there is only one instance of it in the scene.
\item Receives data from an Eye\+Tracker (or something that pretends to be) via its public \doxylink{class_edia_1_1_eye_1_1_eye_data_handler_a9a65cbb3a7b4c19796826bc1023ebd9c}{Add\+Eye\+Data\+Package()} method.
\item Puts these samples into an internal list {\ttfamily \+\_\+current\+Samples}
\item Manages a list of registered {\ttfamily Data\+Clients} (objects implementing the {\ttfamily \doxylink{interface_edia_1_1_eye_1_1_i_eye_data_client}{IEye\+Data\+Client}} interface).
\item At the end (!) of each frame, the class\+:
\begin{DoxyItemize}
\item Locks access to the {\ttfamily \+\_\+current\+Samples} list for thread safety.
\item Sends the collected samples to all registered {\ttfamily Data\+Clients} using their {\ttfamily Process\+Current\+Samples()} method.
\item Empties the {\ttfamily \+\_\+current\+Samples} list
\item Releases the lock to allow further data collection. 
\end{DoxyItemize}
\end{DoxyItemize}
