Detailed Description

Data container for one single frame of eye data from an eye tracker.

This class holds various properties related to the eye's position, orientation, gaze direction, pupil size, and timestamps. It can be used to track eye movements, gaze points, and eye state (such as pupil diameter and openness) for further analysis.
